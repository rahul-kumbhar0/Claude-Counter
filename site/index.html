How it works

Six moves. Zero surprises.

Scroll through a session. The window on the right is the real extension's behaviour, step by step.

01 · Measure

The bar docks under the message box.

Both windows that Claude counts, with reset times, plus how heavy this chat is and how many messages you have left. Read from Claude's own usage data the moment you open a chat.

No setup. Install, open claude.ai, it's there.
02 · Learn

Every send teaches it your real cost.

It watches the meter move after each message, with the model and chat size, and turns that into a learned "messages left" instead of a guess. Opus and long chats get their own honest number.

Use it when you have eight things to ask before the reset.
03 · Warn

You hear about the wall before you hit it.

In-page alerts at 80% and 95%, a toolbar badge that turns amber then red, and a desktop notification the moment a window resets so you come back exactly when there's room.

Use it when you step away and don't want to guess.
04 · Start fresh

One click carries the context, not the weight.

A summary of the goal, decisions, latest code and recent messages is built from the chat and dropped into a new one. Same thread, a fraction of the cost per message, and Claude stops forgetting the top.

Use it when the chat meter is past half.
05 · Carry

Out of room? Take it to another AI.

The summary is typed into ChatGPT, Gemini or Grok, and the whole conversation downloads as Markdown to attach. Unlimited, and nothing is uploaded by the extension itself.

Use it when the window is full and the deadline isn't moving.
06 · Keep

Everything you made, saved on your machine.

One folder per chat: readable HTML, Markdown, raw JSON, every artifact version, code blocks, files and project knowledge. Incremental, so the second run only saves what changed. Claude Code sessions too.

Use it when you'd hate to lose it. Which is always.

Privacy

Your chats never leave your computer.

What it does

  • Reads your own usage and chats inside your browser, with the login you already have
  • Observes the page's own requests to learn cost per message, never changes them
  • Writes backups only to the folder you pick, or a ZIP you download
  • Keeps settings, history and prompts in the extension's local storage
  • On "Carry to", types text into that site's box and downloads a file. You decide what to send

What it never does

  • Never sends chats, files, keys or usage to any server
  • Never sends messages to Claude on your behalf
  • Never shows ads, sells data or phones home
  • Never needs an account, API key or extra login
  • Never touches sites other than claude.ai and the AI you explicitly carry to

FAQ

Common questions.

Is everything really free?
Yes. Every feature on this page, with no quotas and no account. There is no Pro tier. If the project ever needs support to keep going, that will be optional, never a wall in front of a feature.
How accurate are the meters?
The 5-hour and weekly percentages and reset times come from Claude's own usage endpoint, the same data as Settings → Usage. Chat weight and "messages left" are estimates and are marked with ~. Messages-left switches from a documented baseline to a learned figure once it has watched a couple of your own messages.
How does "messages left" learn?
Each time you send a message, Wiggleroom notes the meter before and after, plus the size of the chat and the model used. It keeps the median cost per 1k tokens of context, so a long Opus chat and a short Sonnet chat each get their own realistic number.
How does "Start fresh" save usage?
Every message re-sends the whole chat. A fresh chat that starts with a 2–4k-token summary instead of a 150k-token history costs a fraction per message and gives Claude a cleaner context. You always review the summary before sending it.
What if Claude changes its website or API?
The usage parser is tolerant: it looks for any usage-shaped data in what the page already receives, not one fixed field name. The bar renders in its own Shadow DOM and positions itself relative to the message box, so layout changes rarely break it. When something does, an update follows.
Does it work with Claude Code?
Yes. The bar runs on claude.ai/code and can back up web sessions; the local exporter page reads the .jsonl transcripts from Claude Code on your machine (terminal, desktop app, VS Code, JetBrains).
Will it interfere with Claude?
It never sends messages, never modifies requests and only reads data your browser already has as a logged-in user, the same as opening the usage page yourself. It's a read-and-render tool.
Is this made by Anthropic?
No. Wiggleroom is independent and not affiliated with or endorsed by Anthropic.
